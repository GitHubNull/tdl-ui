# 脚本调试与错误处理

难度：高级

脚本出问题不会搞垮下载任务 —— 引擎为每类错误都设计了兜底行为。本章介绍调试工具链与各种错误的处理机制。

## 调试工具链

### 校验（保存前静态检查）

「脚本」页的「校验」按钮会完整编译脚本并检查契约：

- Go 语法错误 → 显示编译错误与行号
- 契约函数签名不匹配 → 提示正确签名（如 `Filter 签名错误，应为 func(api.FileInfo) bool`）
- 未定义任何契约函数 → 报错「脚本未定义任何契约函数」

### 试运行（无需真实下载）

「试运行」按钮用**内置示例文件**调用你的 `Filter` 和 `Rename`，结果输出到日志面板。适合在创建真实任务前快速验证过滤条件与命名逻辑。

### 脚本日志面板

`api.Log` / `api.Logf` 的输出实时显示在「脚本」页底部的日志面板，是运行期唯一的观察窗口。建议在关键分支处埋点：

```go
func Filter(f api.FileInfo) bool {
	keep := f.FileSize > 1024*1024
	if !keep {
		api.Logf("跳过 %s：仅 %d 字节", f.FileName, f.FileSize)
	}
	return keep
}
```

## 错误处理机制

### panic 自动恢复

脚本中的 `panic`（空指针、数组越界、显式 panic 等）会被引擎捕获，**不会中断下载任务**，错误信息记录到脚本日志。各函数的兜底行为：

| 函数 | panic 后的兜底行为 |
| --- | --- |
| `Filter` | 默认**保留**该文件（宁多勿漏） |
| `Rename` | 回退到默认命名模板 |
| `OnTaskStart` / `OnFileDone` / `OnTaskDone` | 忽略本次调用，任务继续 |

### 10 秒超时与熔断

每次契约函数调用有 **10 秒超时**。一旦超时：

1. 本次调用按上表兜底处理
2. 该函数被**熔断禁用**——本任务后续不再调用它（日志提示「XX 执行超时，已熔断禁用该脚本函数」）
3. 其余契约函数不受影响

熔断的目的是避免死循环脚本对每个文件重复等待 10 秒。写循环时务必确认退出条件：

```go
// ❌ 危险：条件永不满足时死循环，10 秒后 Filter 被熔断
for !strings.Contains(name, "x") {
	name = transform(name)
}

// ✅ 安全：限制迭代上限
for i := 0; i < 100 && !strings.Contains(name, "x"); i++ {
	name = transform(name)
}
```

### 沙箱违规

导入白名单之外的包（`os`、`net` 等）属于**编译期错误**，在「校验」或保存时即被拦截，不会进入运行期。

## 常见错误对照表

| 报错 / 现象 | 原因 | 解决 |
| --- | --- | --- |
| `脚本编译失败: ... undefined: os` | 导入了沙箱禁止的包 | 只使用白名单内的 14 个标准库包 |
| `Filter 签名错误，应为 func(api.FileInfo) bool` | 参数或返回值类型写错 | 对照「内置函数与类型参考」修正签名 |
| `脚本未定义任何契约函数` | 函数名拼写错误（如 `filter` 小写） | 契约函数名首字母必须大写且完全一致 |
| 日志出现 `脚本 panic: ...` | 运行期 panic | 根据 panic 信息定位，注意空串、除零、越界 |
| 日志出现 `XX 执行超时，已熔断禁用` | 函数单次执行超过 10 秒 | 排查死循环/重量级计算；重新创建任务恢复 |
| Filter 没生效，文件全下载了 | 脚本 panic 后兜底保留文件 | 查看脚本日志中的 panic 信息 |
| Rename 没生效，用了默认命名 | 返回了空串，或脚本出错回退 | 确认返回值非空；查看日志 |

## 调试流程建议

1. **先校验**：语法与签名问题在保存前解决
2. **再试运行**：用示例数据验证 Filter/Rename 逻辑
3. **小任务实测**：选一个只有几个文件的对话创建任务，观察脚本日志
4. **加日志缩小范围**：在分支处用 `api.Logf` 打印中间值
5. **批量使用**：确认无误后再用于大批量下载
