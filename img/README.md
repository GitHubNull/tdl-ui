# tdl UI 视觉素材库

本目录存放 tdl UI（跨平台 Telegram 下载工具）的全套官方视觉素材，包括 Logo、应用图标、界面功能图标、插图与宣传材料。

## 设计理念

**核心视觉符号：「下行纸飞机 + 接收托盘」**

将 Telegram 的纸飞机意象旋转向下，与"下载箭头"形态融合——纸飞机的 V 形轮廓即是下载箭头的箭头部分，下方的圆角托盘代表本地存储的"接收端"。一个符号同时表达产品的两个核心语义：**Telegram（来源）** 与 **下载（能力）**。

**风格关键词**：几何极简 · 圆角亲和 · 品牌蓝 · 明暗双主题适配

设计系统与应用内 UI 完全对齐（PrimeVue Aura 主题 / 8px 栅格 / 10–12px 圆角，参见 `src/frontend/src/style.css` 与 `main.ts`）。

## 使用建议

1. **Wails 应用图标**：将 `logos/app-icon.ico` 复制到 `src/build/windows/icon.ico`，PNG 版用于 macOS/Linux 打包。
2. **favicon**：在 `src/frontend/index.html` 中引用 `app-icon-png/app-icon-32.png`（或直接引用 `app-icon.svg`）。
3. **侧边栏品牌位**：可用 `logo-mark-mono-light.svg` 替换现有文本 "tdl"（当前品牌位为蓝底，白色单色版对比度最佳）。
4. **导航图标接入**：SVG 均使用 `currentColor`，以内联 SVG 或 SVG 组件方式引入即可继承现有 `.nav-item` 的颜色状态（默认/hover/active）。
5. **修改素材**：优先编辑 SVG 源文件后重新导出位图，保持矢量母版为唯一事实来源。

## 无障碍与质量

- 所有 SVG 均含 `<title>`（及必要的 `<desc>`）与 `role="img"`，可被屏幕阅读器识别。
- 状态图标白色符号与语义色底的对比度满足 WCAG AA；导航图标继承文字色，对比度由主题保证。
- 全部图标已通过 16px 缩小辨识测试与明暗双背景视检。
