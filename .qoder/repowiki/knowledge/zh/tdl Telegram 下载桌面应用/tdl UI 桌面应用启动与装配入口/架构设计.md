本模块为 Go 单包 main 程序，作为整个应用的启动与装配中心：
- 启动流水线：`main()` 按序执行 `config.NewManager` → `logging.Init`（支持从 data 目录导入 logging.yaml）→ `kv.New`（bbolt 全局 KV 单例）→ `store.Open`（SQLite tasks.db，首次导入旧 tasks.json）→ 组装 `engine.Manager` 与各 `services.*Service`（Auth、Download、Script、Settings、Chat、Log），最后通过 `wails.Run(...).Bind` 暴露给前端。
- 依赖方向单向向外：仅依赖 `internal/*` 子包与第三方库（Wails、Yaegi、gotd/tdl），不被 internal 反向引用。
- 资源嵌入：通过 `//go:embed all:frontend/dist` 将前端构建产物打包进二进制，由 `assetserver.Options` 提供静态服务，并注入本地文件解析器以零 API 消耗回放已下载媒体。
- 生命周期钩子：`OnStartup` 绑定事件发射器，`OnShutdown` 严格按「解绑事件 → 停止下载任务与 Chat 常驻连接 → 关闭存储与日志」顺序释放资源，避免并发与数据库关闭错误。
- 外部依赖：核心下载能力来自 Git 子模块 `ref/tdl`，通过 go.mod 的 `replace` 指令本地替换引入，禁止直接修改子模块。
