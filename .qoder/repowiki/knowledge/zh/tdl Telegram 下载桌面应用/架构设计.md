仓库以 src/ 为唯一源码目录，ref/tdl 作为 Git 子模块通过 go.mod replace 引入且严格只读；src/internal/ 提供 AuthService、ChatService、DownloadService、ScriptService、SettingsService 等 Go 后端服务，通过 Wails 事件契约（login:update、task:update、task:file、script:log）与 Vue 3 前端交互。bolt kv 全局单例由 bbolt 文件锁保证会话存储一致性，ChatService 采用懒启动 + 断线重建 + jobs 通道串行化避免并发问题。下载任务状态机遵循 queued → running ↔ paused → done/failed/canceled 六态流转，暂停等价取消并保留 resume key，恢复即重跑+断点续传。Yaegi 脚本引擎在沙箱中执行 Go 代码，禁用 os/exec 等危险包并内置 10 秒超时与 panic 恢复保护主程序。
