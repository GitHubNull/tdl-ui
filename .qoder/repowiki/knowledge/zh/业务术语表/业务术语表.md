### 选集下载
- 定义：从 Telegram 对话中勾选特定媒体文件进行批量下载的交互模式。用户在对话页右侧面板勾选多个文件后，点击「下载选中」按钮创建下载任务。支持按文件类型、关键词、大小等条件筛选，是项目的主要下载路径之一。
- 别名：selection download、批量下载

### ChatService 常驻连接
- 定义：Telegram 聊天服务的长连接管理机制。ChatService 在应用启动时建立并维护与 Telegram 服务器的持久连接，支持断线自动重建、错误恢复和消息推送。相比每次操作新建连接，常驻连接提供更好的性能和用户体验。
- 别名：chat connection、Telegram 连接

### ARC-05 约束
- 定义：项目架构约束编号 ARC-05，特指 `ref/tdl` 上游子模块的只读约束。该约束规定 tdl 上游代码只能通过 Git 子模块方式引入，禁止直接修改，仅允许同步上游变更。所有依赖版本由子模块的 go.mod 固定，确保与上游保持一致。
- 别名：子模块约束、上游只读

### YAML 配置热重载
- 定义：应用配置文件（config.yaml）的热重载机制。当配置文件发生变化时，应用能够自动检测并重新加载配置，无需重启进程。支持注释、分组结构和默认值，首次启动时自动迁移旧版 settings.json 格式。
- 别名：配置热重载、yaml 配置

### 三主题模式
- 定义：应用支持的三种主题显示模式：亮色（Light）、暗色（Dark）、跟随系统（System）。通过 CSS 变量和 matchMedia API 检测系统偏好，localStorage 持久化用户选择。PrimeVue Aura 主题库提供完整的主题切换支持。
- 别名：主题切换、明暗主题

### Wails 服务层 API 契约
- 定义：Go 后端服务与前端之间的接口契约。通过 Wails 框架将 Go 方法暴露给前端 JavaScript，包括 Auth、Chat、Download、Script、Settings 五大服务。前后端类型定义需要保持同步，错误处理遵循统一模式。
- 别名：Wails API、服务绑定

### 六态状态机
- 定义：下载任务的状态流转模型，包含 queued（排队）、running（运行中）、paused（暂停）、done（完成）、failed（失败）、canceled（取消）六种状态。状态转换遵循严格的业务规则，确保任务生命周期管理的正确性。
- 别名：任务状态机、下载状态

### Yaegi 沙箱安全
- 定义：基于 Yaegi 脚本引擎的安全隔离机制。通过白名单/阻断包机制限制脚本可访问的系统资源，禁用危险包（如 os/exec），实现 10 秒超时熔断和 panic 恢复保护。确保用户脚本不会影响主程序的稳定性和安全性。
- 别名：脚本沙箱、安全约束
