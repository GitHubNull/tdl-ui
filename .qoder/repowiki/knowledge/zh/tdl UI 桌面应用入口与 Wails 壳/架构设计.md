本模块是 Go 单包 main 程序，作为 Wails 应用的唯一入口：
- 启动流程：`main()` 依次加载 `config` → 初始化 `logging`（支持从 data 目录导入 logging.yaml）→ 创建全局 bolt KV 实例（`kv.New`，bbolt 文件锁保证单例）→ 打开 SQLite 任务存储并迁移旧 tasks.json → 组装 `engine.Manager` 与各 `services.*Service`（Auth、Download、Script、Settings、Chat、Log）→ 通过 `wails.Run` 绑定到前端。
- 依赖方向单向向外：仅依赖 `internal/*` 子包与第三方库（Wails、Yaegi、gotd/tdl），不反向被 internal 引用。
- 资源嵌入：通过 `//go:embed all:frontend/dist` 将前端构建产物打包进二进制，由 `assetserver.Options` 提供静态服务。
- 生命周期：`OnStartup` 绑定事件发射器，`OnShutdown` 按顺序解绑事件、停止下载任务与 Chat 常驻连接、关闭存储与日志，避免并发与数据库关闭错误。
- 外部依赖：核心下载能力来自 Git 子模块 `ref/tdl`，通过 go.mod 的 `replace` 指令本地替换引入，禁止直接修改子模块。
