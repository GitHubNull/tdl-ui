| `2026-07-29-full-audit/` | 2026-07-29 | ARC/DEP/AUTH/SVC/ENG/STO/SCR/LOG/FE（按模块分文件） | ~60（Critical 1 / High 12 / Medium 27 / Low 20） | 骨架正确、边界场景欠打磨；全部发现已按 P0-P3 路线图修复完毕 |

## 约定

1. 每轮目录内含：`README.md`（总览与汇总表）、若干分报告、`XX-remediation-roadmap.md`（P0-P3 路线图）。
2. 各轮次的发现 ID 命名空间互相独立，跨轮引用时须写全轮次目录名。
3. 报告读者是 AI 编程代理：以符号名定位代码，行号仅供参考；严禁包含时间估算类字段。
4. 新一轮审计照此新建 `{yyyyMMdd-HHmm}-{语义名}/` 目录，并在上表追加一行。
