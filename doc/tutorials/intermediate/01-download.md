# 创建下载任务

难度：🟡 进阶 | 前置：[账号登录](../basic/02-login.md)

## 方式一：从对话中选集下载（推荐）

登录后，打开「对话」页，以双面板形式浏览所有对话和媒体文件：

### 1. 选择对话

- 左侧面板显示全部对话（私聊 / 群组 / 频道），支持：
  - **搜索**：按标题或用户名搜索，支持正则表达式
  - **类型过滤**：全部 / 私聊 / 群组 / 频道
  - **排序**：按最近消息时间或按标题字母序
- 点击对话条目，右侧面板加载该对话的媒体文件

### 2. 浏览与筛选媒体

右侧面板以卡片网格展示媒体文件，支持以下筛选：

| 筛选条件 | 说明 |
| --- | --- |
| 关键词 | 搜索文件名或消息说明文字 |
| 类型 | 视频 / 图片 / 音频 / 文件（可多选） |
| 扩展名 | 如 `mp4, jpg`（逗号分隔） |
| 大小范围 | 最小 MB ~ 最大 MB |

媒体卡片显示缩略图（图片/视频有清晰预览）、文件名、大小、扩展名和日期。点击卡片可勾选/取消勾选。

### 3. 创建下载任务

- 勾选需要的文件后，点击「下载选中」
- 在弹出的对话框中选择保存目录、可选的过滤/命名脚本
- 勾选选项：下载整组相册 / 跳过同名同大小文件 / 按 MIME 修正扩展名
- 点击「创建下载任务」，自动跳转到「下载」页查看进度

> 也可点击单个卡片上的 ⬇️ 按钮直接下载该文件。

## 方式二：粘贴消息链接

适用于没有对话访问权限但拥有消息链接的场景：

1. 在 Telegram 中右键（或长按）包含媒体的消息 → **复制消息链接**：
   - 公开频道 / 群组：`https://t.me/频道名/消息ID`，如 `https://t.me/telegram/123`
   - 私有频道 / 群组：`https://t.me/c/内部ID/消息ID`，如 `https://t.me/c/1234567890/456`

2. 打开「下载」页，点击右上角「添加下载」
3. 在对话框中粘贴链接（**每行一条**），可一次粘贴多条
4. 选择保存目录、可选脚本，勾选选项，点击创建

> 私有频道链接要求当前登录的账号本身是该频道成员。

## 任务管理

「下载」页中每个任务卡片显示状态、总进度与进行中文件的实时进度：

| 状态 | 说明 | 可用操作 |
| --- | --- | --- |
| 排队中 / 下载中 | 正在解析或下载 | 暂停、取消 |
| 已暂停 | 进度已保留 | 恢复（断点续传）、取消 |
| 已完成 / 失败 / 已取消 | 终态 | 移除记录 |

### 断点续传

暂停或应用退出后，已下载的部分不会丢失。点击「恢复」（或重新创建相同链接的任务）会从上次中断的位置继续下载 —— 此机制与 tdl CLI 完全一致。

## 文件命名

默认文件名格式为 `{对话ID}_{消息ID}_{原始文件名}`，可在「设置」页修改模板，或用脚本完全自定义（见高级教程）。
