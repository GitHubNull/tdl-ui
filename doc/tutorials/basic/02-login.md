# 账号登录

> [← 教程目录](../README.md) | [项目主页](../../../README.md)

难度：🟢 入门

tdl UI 提供三种登录方式，任选其一。登录成功后会话保存在本地，下次启动无需重复登录。

## 方式一：二维码登录（推荐）

1. 打开「账号」页（左侧导航栏底部 👤 图标），切换到 **二维码登录** 标签
2. 点击「生成二维码」
3. 手机 Telegram 打开 **设置 → 设备 → 关联桌面设备**，扫描屏幕上的二维码
4. 若账号开启了二步验证，界面会提示输入密码
5. 登录成功后页面显示账号信息

> 二维码会自动刷新，若过期重新扫描即可。

## 方式二：验证码登录

1. 切换到 **验证码登录** 标签
2. 输入手机号（**必须含国际区号**，如 `+8613800000000`），点击「发送验证码」
3. 在手机 Telegram（或短信）中查收验证码并输入提交
4. 若开启了二步验证，继续输入密码
5. 登录成功

常见问题：

- **收不到验证码**：确认区号正确；验证码通常发到已登录的 Telegram 客户端而非短信
- **提示 FLOOD_WAIT**：请求过于频繁，等待提示的秒数后重试

## 方式三：Telegram Desktop 会话导入

如果本机已安装并登录了 Telegram Desktop，可直接导入其会话，免去重新登录：

1. 切换到 **Desktop 导入** 标签
2. 点击「自动探测」，应用会查找本机 Telegram Desktop 数据目录（也可手动输入路径）
3. 若 Desktop 设置了本地密码，填入「本地密码」，否则留空
4. 点击「读取账号」，从列出的账号中选择要导入的，点击「导入该账号」

> ⚠️ 导入的会话与 Telegram Desktop 共用。在任一端「退出登录」会使会话失效。

## 退出登录

「账号」页 → 「退出登录」按钮，将清除本地会话数据。
